## 打开与操作

1. 在团结 Hub 中添加本目录，使用 `2022.3.61t14` 打开。工程已在这台电脑完成初始化，无需等待 Unity 6 下载。
2. 打开 `Assets/Night3Whitebox/Scenes/Night03_FootstepsCloser.scene`。
3. 点击编辑器 Play，然后点击 Game 画面使其获得键盘焦点。默认显示剖面总览。

| 操作 | 按键 |
|---|---|
| 第一人称空间走查 / 剖面总览 | `1` / `2` |
| 移动 | `WASD` 或方向键 |
| 转动视角 | 点击 Game 画面后移动鼠标 |
| 蹲下 / 站起 | `C` |
| 附近门扇开关 | `E`，靠近门中心约 1.7 单位内 |
| 返回卧室起点 | `R` |
| 释放鼠标 | `Esc` |

建议顺序：卧室 → 客厅 → 家长房门口 → 书房／餐厅 → 储藏区／杂物区 → 洗衣区绿色目标 → 返回卧室。空间走查可自由选择路线。走查模式显示完整墙高及天花板；总览仅隐藏墙体上部的渲染，原始碰撞仍完整。

## 建模内容与数据依据

- 24 × 19 网格范围内的 L 形住宅，墙高 2.6，门洞高 2.2，带门框后的净宽约 0.92；此白盒采用 1 单位约 1 米。
- 266 个地板模块、150 个墙体模块、16 个门洞模块、2 扇可动门。
- 17 个可复用 Prefab：墙、地板、门洞、门扇，以及床、柜、台灯、沙发、桌、电视、椅子、书架、盆栽、书桌、纸箱、厨房柜、洗衣机共 13 类家具。
- 33 个家具实例保留原第三关的坐标、朝向和外包尺寸，继续保持与 Prefab 的连接。家具为自制基本几何组合，未使用购买模型或生成式 3D 素材。
- 卧室起点 `(3,12)`、洗衣区取物柜 `(12,17.12)`、地毯、少量桌面物和睡眠人物尺寸代理，辅助判断场所用途和遮挡关系。
- 行走速度 2.05、蹲行速度 1.05 单位/秒，角色半径 0.20，站立／蹲行眼高约 1.37 / 0.85，FOV 78，取自原游戏对应参数；团结使用 CharacterController 实现基础走查，不能视为完整复现原游戏运动手感。

`Data/Night3Layout.json` 是当前布局数据快照；`Editor/WhiteboxBuilder.cs` 通过编辑器 API 创建可编辑的 Prefab、材质和原生场景。可直接编辑场景，也可调整数据及生成器后重建。**重建会覆盖本白盒场景和模块，请先复制保存手工改动。**

## 实际验证

| 检查 | 结果及证据 |
|---|---|
| 脚本、材质、场景与 Prefab 连接 | 17 项几何检查全部通过；`Evidence/geometry-validation.json` |
| 三维碰撞可达性 | 开门状态下 2,904 个四分之一单位采样节点可达，8 个目标均有路径 |
| Play Mode 实际碰撞走查 | 8 条路线全部抵达并返程；`Evidence/playmode-walkthrough.json` |
| 原生界面输入 | `1` 切换、W 移动、C 蹲行与站立、E 开门实际响应；`Evidence/ui-input-check.txt` |
| 编辑器控制台 | 完成后的读取中错误、警告均为 0 |
| 图像 | 总览、俯视平面、4 个室内视角和 1 张含界面运行截图，共 7 张 |

Play Mode 路径验证使用真实 CharacterController、20ms 移动子步并加速执行；全部门在路线测试前打开。它验证碰撞连通性，不等于真人可用性测试、完整游戏通关或对原游戏全部机制的验证。E 键门测试单独将角色放在门前后进行；没有把该瞬移当作键盘走完整条路线的证据。

编辑器顶部 `Night Back` 菜单可重新运行 `Validate Geometry`、`Save Evidence Images`。先做几何验证生成路线，再进入 Play Mode，选择 `Run Play Mode Walk Check` 可重跑物理走查。
